Projetos

  1. Hackathon SEMCOMP × iFood · em grupo

    CompletAi

    Um agente que recebe texto, foto ou voz e devolve receitas e produtos. Ele usa o OpenAI Agents SDK conectado ao MCP oficial do iFood para buscar ofertas e só monta o carrinho depois que a pessoa confirma. Tem login OAuth com PKCE, testes automatizados e cuidado com acessibilidade.

    React · TypeScript · FastAPI · OpenAI Agents SDK · MCP

    código

  2. Hackathon de Dados Abertos · IFSP Araraquara · em grupo

    AgroGuard

    Risco ambiental e aptidão agrícola por município, calculados a partir de dados públicos do INPE, IBGE, ANA/Embrapa e MAPA. A API em FastAPI processa o volume de dados e gera scores explicáveis de queimadas, clima e agricultura, que aparecem num mapa em React. Um LLM ajuda a interpretar os resultados.

    FastAPI · React · Gemini · dados abertos

    api frontend

  3. TCC · Técnico em Informática · IFSP

    CineBrasil

    Uma plataforma para descobrir, avaliar e discutir filmes brasileiros, com catálogo, busca e paginação, contas de usuário, perfis, listas, comunidades, publicações e análises. O catálogo é enriquecido pela API do TMDB.

    PHP · JavaScript · MySQL · Bootstrap · TMDB
